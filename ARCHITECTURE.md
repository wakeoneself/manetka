# Устройство проекта

`src/` — React/TypeScript UI. `model.ts` описывает предметную модель и узкий API. `demo.ts` содержит только демонстрационные данные с адресами RFC 5737. В production код демонстрации не получает доступ к SSH; работающие операции явно блокируются в демо.

`electron/main.ts` — окно, меню, lifecycle, безопасный протокол локальных ресурсов, IPC, native file dialogs, rate limit разблокировки, таймер блокировки. `preload.ts` — изолированный allowlist-bridge; renderer не получает ipcRenderer, filesystem, SSH-клиент или shell.

`electron/core/vault.ts` — формат зашифрованного хранилища, KDF, atomic persistence, редактированный public state, создание файлов без перезаписи, копия с тем же паролем и проверка внешних изменений.

`vault-library.ts` — независимые файлы, каталог недавних путей, выбор/создание/закрытие, обнаружение перемещённых файлов и импорт списка старых файлов из каталога monetka без изменения самих хранилищ. `file-write.ts` публикует новый файл без замены существующего, с fallback для ФС без hard links.

`validation.ts` — строгие Zod-схемы входных параметров и расшифрованного файла; проверка ID, ссылок, ключей, IP, доменов, путей и параметров AWG.

`controller.ts` — прикладные операции и сериализация изменений. Профили содержат серверы, маршруты и конфиги. Один IPv4 добавляется только один раз во всём хранилище. У сервера есть отдельный ownerId, pinned SSH fingerprint, credential, настройки протоколов и состояния new/verified/partial/ready/error. Создание/провиженинг журналируются до remote mutation. Отзыв признаётся успешным только после применения нового набора клиентов на сервере.

`ssh.ts` — SSH host verification, подключение, выполнение через stdin, SFTP atomic replace. Сырой stderr не отображается и не сохраняется, чтобы ключи и конфиги не попали в журнал.

`install-output.ts` — ограниченный поток установочных сообщений: распознаёт пакеты APT, процент curl, зависимости Go и события сборки. Весь остальной текст отбрасывается. Парсер работает с разрывами строк между чанками, CR, UTF-8, лимитом строки 4096 символов и ограничением частоты. Нормализация включается явно только для команд установки; вывод конфигов и скрипты команд через IPC не передаются.

`OperationProgress.tsx` — текущая операция, фазы, таймер, последнее состояние команды, признаки тишины, консоль и автопрокрутка. Progress-события содержат время, тип, ID команды и состояние. SSH и команды сообщают heartbeat каждые 5 секунд; heartbeat сообщает ожидание, а не гарантирует движение удалённой команды. Результат stdout ограничен 1 МиБ, но поток продолжает читаться, чтобы не вызвать SIGPIPE у удалённого процесса. В памяти UI сохраняется ограниченная история вывода; на диск она не записывается.

`ssh-keys.ts` — генерация Ed25519, разбор приватных ключей, fingerprint, связи серверов во всех профилях, разрешение credential по ID и миграция старых inline-ключей. Приватные материалы не входят в public state. Pending-ссылка защищает автоматически создаваемый ключ до завершения проверенного входа.

`protocols.ts` — чистые генераторы X25519, WG/AWG, Xray JSON и VLESS URI. REALITY TCP использует Vision; XHTTP и WebSocket его не используют. WebSocket Xray слушает loopback, TLS завершает Caddy.

`provision.ts` — шаги установки, проверка портов, checksum downloads, systemd, firewall rollback и повторная проверка SSH. `scripts.ts` — поддерживаемые shell-фрагменты, unit files, firewall и cleanup. `downloads.json` — закреплённые версии/хэши источников.

Для новых протоколов нужно расширить типы и схемы, добавить генератор, установку, проверку состояния, отзыв и удаление. Недостаточно добавить пункт в выпадающий список.

## Правила Xray и релеев

Vision только для REALITY/TCP, отсутствие flow у XHTTP/WS, отдельная роль relay, SSH как транспорт провиженинга. Глобальный flush firewall и выключение UFW не используются.

## Проверки

`tests/vault-library.test.ts` — создание при неизвестном старом пароле, сохранность старых байтов, переносимость, режимы доступа, канонические пути и алиасы, недоступные файлы, очистка только списка, восстановление повреждённого каталога, гонка создания и конфликты внешних изменений, открытая и закрытая копия с тем же паролем. Нативный smoke дополнительно проходит забытый пароль, отмену выбора места, второе хранилище, переключение, копию, открытие копии и путь для Finder. `scripts/check-vault-files-ui.mjs` проверяет экран входа, создание, забытый пароль, отсутствующий файл и две темы.

`tests/install-output.test.ts` — фильтрация stdout/stderr, скрытие ключей и неизвестных строк, чанки и CR, ограничения объёма/частоты, доставка до завершения, heartbeat и очистка таймеров, тайм-ауты и большой stdout без SIGPIPE. Loopback SSH-тест проверяет фактическую доставку установочных событий до выхода команды.

`scripts/check-provisioning-ui.mjs` — поток событий через тестовый API в браузере, запуск/ошибка/повтор/завершение, таймер, тихая команда, автопрокрутка и чтение старых строк, сворачивание журнала, темы и компактное окно. Реальные VPS не используются.

`tests/ssh-keys.test.ts` — совместимость зашифрованного Ed25519 с OpenSSH, запрет удаления в каждом состоянии и другом профиле, свободные ключи, секреты в public state, миграция и дедупликация старых файлов, проверка ссылок, журналирование и повтор прерванной установки. `tests/ssh.test.ts` дополнительно проверяет подпись при входе с зашифрованным ключом из реестра.

`scripts/check-ssh-keys-ui.mjs` — раздел ключей, диалоги, обе темы и компактное окно. Нативный smoke-тест дополнительно проверяет генерацию из раздела и мастера, копирование публичной части, привязку и запрет удаления через IPC, удаление свободного ключа и сохранение связей после блокировки.

`tests/vault.test.ts` — round trip, nonce/salt, неверный пароль, повреждение, секреты в public state, mode 0600/0700, dangling references.

`tests/ssh.test.ts` — временный ssh2 server на loopback; отсутствие аутентификации до pinning, отказ при смене ключа, отсутствие stderr-секрета в ошибке.

`tests/provision.test.ts` — входная валидация, shell quoting, WG/AWG параметры, Xray flow, URI encoding, bash parsing, собственные firewall chains.

Проверка запрета парольного входа полностью читает вывод `sshd -T`: `grep -q` в таком конвейере вызывал SIGPIPE/141 при включённом pipefail. Регрессионный тест воспроизводит прежний сбой, проверяет большой вывод, отсутствие нужной настройки и настоящий ненулевой статус производителя. `pipefail` остаётся включённым.

`scripts/check-ui.mjs` — реальные браузерные снимки, поиск, диалоги, Escape, смена темы, мастер моста, небольшой desktop. `scripts/smoke-electron.mjs` — нативное приложение, sandbox/context isolation, создание/блокировка/разблокировка хранилища, запись сервера без SSH и закрытие/повторное открытие окна. Все пользовательские тестовые данные находятся во временном каталоге.

`resource-namespace.ts` задаёт `manetka` для новых записей серверов и прежний `monetka` для старых. Шаблоны команд и путей используют это значение до подстановки пользовательских данных; содержимое конфигов, домены и ключи не подвергаются текстовому переименованию.
