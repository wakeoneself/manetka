# 0.2.1

- Название приложения maNETka, технические имена manetka, расширение новых хранилищ .manetka.
- Совместимость с прежними .monetka и monetka.vault, импорт списка недавних файлов без переноса самих хранилищ.
- Существующие серверы сохраняют прежние служебные пути; новые используют manetka.

# 0.2.0

- Отдельные переносимые .manetka со своими паролями, недавние файлы, выбор места сохранения и показ файла в папке.
- «Забыли пароль?» позволяет создать новое хранилище без изменения прежнего файла.
- «Сохранить копию» создаёт полный зашифрованный .manetka с тем же паролем; копия открывается как обычный файл. ZIP API и fflate удалены.
- Старый manetka.vault подхватывается без переименования. Имя текущего файла видно во время работы.
- Защита от перезаписи при создании, сохранение прав пользовательских папок, обнаружение внешнего изменения файла. Удаление записи из списка не удаляет файл.

# 0.1.2

- Отдельный экран выполнения VPN-настройки с этапами и таймером.
- Живой журнал установки: нормализованные сообщения пакетов, скачивания и сборки; приватные материалы не транслируются.
- Heartbeat тихих команд, метки времени, сворачивание журнала, автопрокрутка с паузой при чтении старых сообщений.
- Результат остаётся открытым; при ошибке можно запустить восстановление с сохранёнными ключами.
- Для фонового восстановления и других операций журнал открывается из индикатора операции.
- Проверены фильтрация, ограничения потока, SSH-доставка до завершения команды, тайм-ауты и оба оформления интерфейса. Полная установка на реальном VPS отдельно не выполнялась.

# 0.1.1

- Исправлен преждевременный выход из проверки `sshd -T`, вызывавший код 141 при усилении SSH. Проверка отключённого парольного входа и обработка реальных ошибок сохранены.
- В журнале установки явно показывается этап «Усиление SSH».
- Добавлен регрессионный тест для ошибки 141 и некорректных настроек.

После обновления полностью закройте приложение и откройте снова. Для сервера с прерванной установкой выберите «Восстановить настройки»: приложение повторно использует сохранённые ключи и конфиги. Работа на реальном VPS в рамках этой проверки не выполнялась.
